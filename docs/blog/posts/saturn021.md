# Saturn Engine Alpha 0.2.1 Released 🎉

Last Updated: 27 May 2025

Today, I have released an update for Saturn.

Changes:

- CB Thumbnails
- Undo/Redo
- Quick Actions for CB
- Initial nav mesh
- Frustum Culling
- Reworked Uniform buffers
- Fix ImGui viewport issue (windows lower in the z-order could receive mouse events)

The build is not available to downloaded but you can build it from source using [this link](https://github.com/0xsmft/Saturn-Engine/releases/tag/alpha-0.2.1).
