# Saturn Engine Alpha 0.1.4 Released 🎉

Last Updated: 1 January 2025

Happy new year!

Today, I have released an update for Saturn.

Changes:
- SProperty
- Set Properties from editor exposed from C++
- Hot Reloading
- Add support for XBUTTONS on mouse (Mouse3, Mouse4 etc)
- Various bug fixes
- Add external C++ header tool
- Faster build tool
- Saturn Build Tool Version 0.0.3
- Better PlayerInputController

The build is not available to downloaded but you can build it from source using [this link](https://github.com/0xsmft/Saturn-Engine/releases/tag/alpha-0.1.4).
