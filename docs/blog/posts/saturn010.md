# Saturn Engine Alpha 0.1.0 Released 🎉

Last Updated: 27 March 2024

Today, the first ever version of Saturn has been released. It has been almost 4 years since I wrote the first line of code in this engine. I still remember that day.

We have came a long way to get here, from using C++11 then C++14 and now finally C++20. In fact Vulkan wasn't even the original graphics API that was OpenGL.

The build is not available to downloaded but you can build it from source using [this link](https://github.com/0xsmft/Saturn-Engine/releases/tag/alpha-0.0.1).
