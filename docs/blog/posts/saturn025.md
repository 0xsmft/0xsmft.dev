# Saturn Engine Alpha 0.2.5 Released 🎉

Last Updated: 27 May 2026

Today, I have released an update for Saturn.

Changes:
- Standard alpha build.
- Online System (Steam API)
- Jolt Physics
- Selection Outline + jumpflooding
- Worldspace text rendering
- Node Editor Rework
- Replace asset when deleting an asset
- Find Nodes in node editor (Ctrl+F)
- Bloom
- SSAO
- Fix issue with Skeletal Mesh material data
- Texture Streaming
- Content Browser file moving improvements

The build is not available to downloaded but you can build it from source using [this link](https://github.com/0xsmft/Saturn-Engine/releases/tag/alpha-0.2.5).
