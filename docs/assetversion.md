# AssetVersion

8-bit enum.

## Valid versions

| Name  | Numerical Value
| ------| ------|
Before Version Was Added | 0 |
VersionTypeChangedAndClassSize | 1 |

## Notes

The latest asset version is `VersionTypeChangedAndClassSize` or `1`

Each new field in the enum represents a new breaking change.

The latest version change was May 5 2026, in commit [5379a05f](https://github.com/0xsmft/Saturn-Engine/commit/5379a05ff47ef9ab2037191a4dcb5d73b1f4698d).
