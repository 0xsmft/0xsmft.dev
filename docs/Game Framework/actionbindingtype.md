# ActionBindingType

`#include "Saturn/GameFramework/ActionBinding.h"`

8-bit enum.

```cpp
enum class ActionBindingTriggerState : uint8_t
```

The type of the [ActionBinding](actionbinding.md).

The ActionBinding will only respond to the events that it's type is set to.

## Valid bits

| Name | Value |
| ----- | ---- |
| Key | 0 |
| Mouse | 1 |
