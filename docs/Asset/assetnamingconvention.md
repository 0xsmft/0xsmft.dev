# Asset Naming Conventions

This page is purely advice that is optional and doesn't need to be followed.

| Asset Type | Prefix/Suffix | Example 
| -------- | --------- | ------------ |
| Texture | `T` | `TFloor` |
| StaticMesh | N/A (opt. `SM_`) | `Cube` (opt. `SM_Cube`) |
| SkeletalMesh | `SKM_` | `SKM_Human` |
| Material | `M_` | `M_MyMaterial` |
| Sound | `SFX_`/`SND_` | `SFX_Crash`/`SND_Walk` |
| GraphSound | `SG_` | `SG_MyGraphSound` |
| Scene | N/A (opt. `W_`/`Lvl_`/`Scene_`) | `LevelOne` (opt. `W_LevelOne`, `Lvl_LevelOne`, `Scene_LevelOne`) |
| Prefab | `CI` (as a suffix) | `PlayerCI` |
| Skeleton | `SK_` | `SK_Player` |
| PhysicsMaterial | `PhysM_`/`PM_` | `PhysM_MyPhysMat`/`PM_Floor` |
| BehaviourTree | `BT` (as a suffix) | `MainBT` |
| BehaviourTreeMemory | `BB_` | `BB_Main` |
| SkeletalAnimation | `SK_Anim_`/`Anim_` | `SK_Anim_Walk`/`Anim_Walk` |
| AnimationController | `AG_` | `AG_PlayerLocomotion` |
| Font | `AF_` | `AF_NotoSans` |
| StyleProfile | `ASP_`/`SP_` | `ASP_MainMenuStyling`/`SP_MainMenuStyling` |
| PhysSurfaceRegistry | `PSR_` | `PSR_Main` |
| ShaderPrototype | `GL_` | `GL_ToonShader` |
